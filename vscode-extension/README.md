# GPU Monitor — VS Code Extension

VS Code extension for monitoring GPU statistics (temperatures, clocks, VRAM, power, fans, throttling) in real time via the LACT API (see the `lact-api` folder in this repository).

## Features

- Webview dashboard with per-GPU cards: clocks, voltage, power usage, temperatures, VRAM usage, throttling, fan speed
- Auto-refresh (configurable interval)
- Status bar item showing the **highest** GPU temperature (usually GPU Hotspot)
- Extension version displayed next to the "GPU Monitor" header

## Requirements

- [Node.js](https://nodejs.org) 18+ and npm
- VS Code 1.96.0 or newer
- [LACT](https://github.com/SliverCr/LocalAI) installed with a GPU, plus the `lact-api` service running (see `lact-api/RUNNING_AS_SERVICE.md` in the repository), or any compatible endpoint exposing `lact cli stats` output

## Configuration

| Setting | Default | Description |
|---|---|---|
| `gpuMonitor.apiUrl` | `http://127.0.0.1:3000/gpu/stat` | URL of the LACT GPU stats API endpoint |
| `gpuMonitor.refreshInterval` | `2000` | Auto-refresh interval in milliseconds (1000–60000) |

## How to Compile

```bash
cd vscode-extension

# 1. Install dependencies
npm install

# 2. Compile TypeScript to dist/
npm run compile
```

The compiled extension entry point is `dist/extension.js` (see `main` in `package.json`).

## How to Package (.vsix)

Option A — using `vsce`:

```bash
npx --yes @vscode/vsce package --allow-missing-repository --allow-star-activation
# produces gpu-monitor-<version>.vsix
```

Option B — using the VS Code CLI:

```bash
code --install-extension gpu-monitor-<version>.vsix
```

Or simply build the `.vsix` manually (it is a ZIP with the correct layout):

```bash
cd vscode-extension
rm -f gpu-monitor-0.1.1.vsix
zip -r gpu-monitor-0.1.1.vsix . -x "node_modules/*" -x "src/*" -x "*.tsbuildinfo"
```

> Bump the `version` field in `package.json` before packaging a new release.

## How to Install

1. **From a .vsix file (recommended):**
   - VS Code → `Extensions` view (`Ctrl+Shift+X`)
   - `...` menu → **Install from File...**
   - Select `gpu-monitor-<version>.vsix`
   - Or from the terminal: `code --install-extension gpu-monitor-<version>.vsix`

2. **From the marketplace:** publish the `.vsix` with `vsce publish` (requires an OAuth token) and install it like any other extension.

## Usage

1. Make sure the LACT API is running (`lact-api` on port 3000 by default).
2. Run the command **`GPU Monitor: Show Dashboard`** (or use the command palette: `Ctrl+Shift+P` → "GPU Monitor").
3. The dashboard opens in a webview and auto-refreshes.
4. The status bar (bottom right) shows the highest temperature, e.g. `📺 68°C`. Hover for a per-sensor breakdown.

## Development

```bash
npm run watch   # compile in watch mode
```

To debug the extension inside VS Code, open this folder and press `F5` (a launch configuration can be added to `.vscode/launch.json` with `"type": "extensionHost"`, `"request": "launch"`, `"args": ["--extensionDevelopmentPath=${workspaceFolder}"]`).
